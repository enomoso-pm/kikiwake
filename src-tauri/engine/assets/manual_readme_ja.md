# マニュアルの素材（Kikiwake）

この zip は、会議の録画から Kikiwake が作った「マニュアルを書くための素材」です。
AI（Claude など）にこの zip を渡し、「README.md を読んで、その手順でマニュアルを作って」と頼んでください。
絵は共有していた画面の部分だけを切り出し（会議アプリの参加者の枠は、見分けられたときに外しています）、カメラの顔は黒く塗ってあります。それでも、参加者の名前や、画面に映っていたほかの情報（通知・メール・お客さまの情報など）が残っていることがあります。渡す前に `frames/` を見て確かめてください。

---

## AI の方へ（1）この zip の読み方

この録画は、パソコンの画面を共有しながら、操作や手順を説明した会議です。
誰が何を話したか（文字起こし）と、そのとき映っていた画面の絵を、時刻で結んであります。

### 入っているもの

| ファイル | 中身 |
|---|---|
| `timeline.md` | いちばん大事なファイル。録画の時刻順に、区間ごとの絵と、その間の発言を並べたもの |
| `timeline.json` | `timeline.md` と同じ中身のデータ（プログラムで読むとき用） |
| `transcript.md` | 文字起こしの全文（区間に分けていないもの） |
| `frames/` | 画面の絵（JPEG）。`timeline.md` から参照している |

### 区間の種類（timeline.md の見出し）

- **場面の切り替わり**：画面の大半が替わった所。別の画面・別のスライドに移った。マニュアルの章や節の区切りの候補
- **画面の中の変化**：画面の一部だけが替わった所（窓が開いた、メニューが出た、入力した など）。手順の 1 つの候補。「変わった所」に、絵の中の位置を書いてある
- **前と同じ画面**：前に出てきた画面に戻った。絵は、書いてある番号の区間のものを見る
- **一時的な表示**：数秒で元の画面に戻った表示（通知など）。中身が漏れないよう、絵は入れていない
- **カメラの時間**：画面の共有が無く、カメラの映像だけだった時間。絵は入れていない。発言だけを入れている

絵の枚数を抑えるため、次の時間は前後の区間にまとめてあります（時間と発言はまとめた先の区間に入っていて、消えてはいません）。

- 画面が動き続けていた時間（スクロール中、AI の返事や読み込みが流れて出てくる間など）→ そのあとの落ち着いた画面の区間へ
- 5 秒未満で次の画面に移った小さな変化 → 次の区間へ
- 同じ所で続けて起きた小さな変化（同じ欄への入力が続く など）→ 最後の画面の区間へ（「変わった所」は、まとめた範囲全体）

### 読むときの注意

- 絵は、その区間の最後（次の変化の直前）の画面です。読み込みが終わった状態で、次に押すボタンの上にマウスの矢印が乗っていることがあります
- 絵は、共有していた画面の部分だけを切り出してあります（会議アプリの参加者の枠や、まわりの黒い帯を外しました）。見分けられなかった絵は録画の全体のままで、端に参加者の名前などが写っていることがあります
- 絵の中の黒い四角は、カメラに映った人を消した跡です。中身は推測しないでください
- 「顔が写っているかもしれません」と書いた絵には、写真などの顔が残っている可能性があります
- 区間の見出しの下にある「表示していた時間」と「発言」の数は、その画面を中心に話していたかの手がかりです。ただし断定はできません。発言の中身で確かめてください
- 発言は、その発言の真ん中の時刻が入っている区間に置いてあります。画面が切り替わる前後の発言は、となりの区間の画面のことを話している場合があります
- 話者の名前は、文字起こしで付けた名前です（付けていなければ「話者A」など）。「確認用」は、誰の声か決められなかった発言です（雑音の聞き違いのこともあります）
- 文字起こしには聞き間違いがあります。画面の文字（ボタン名・項目名・画面名）と食い違うときは、画面の文字を正としてください
- 発言で「ここ」「この画面」「これを押す」と言っている所は、同じ区間の絵で何を指しているかを確かめてください

## AI の方へ（2）マニュアルの書き方

この素材から、操作の手順書（マニュアル）を作ってください。

1. まず `timeline.md` を最初から最後まで読み、録画全体で何を説明しているか（目的・使う画面・手順の流れ）をつかんでください
2. 絵は、手順を書くのに要る所で `frames/` から開いて確かめてください（全部を一度に見なくてかまいません）
3. 次の形でまとめてください
   - 題名と、このマニュアルで何ができるようになるか（1〜2 文）
   - 前提（使う画面・権限・準備するもの）
   - 手順：番号つきで、1 つの手順に 1 つの操作。画面の名前・ボタン名・入力する値は、画面の文字のとおりに書く。手順ごとに、参考になる絵を `frames/0003.jpg` のように示す
   - 注意点・よくある間違い（説明の中で出た注意や、質問への答え）
   - よくある質問（参加者の質問と、その答え）
   - 出典：手順ごとに、根拠にした区間の番号と時刻
4. 守ってほしいこと
   - 素材に無いことは書かない。分からない所は「（録画では不明）」と書く
   - 推測で手順を補うときは、推測だと分かるように書く
   - 画面に映った個人の情報（メールアドレス・電話番号・お客さまの名前・会議の参加者の名前・通知の中身など）は、マニュアルに写さない。
     そうした情報が写っている絵を手順に示すときは、「（この絵には個人の情報が写っています。配る前に切り抜くか塗ってください）」と書き添える
   - 雑談や、手順に関係のない話は入れない
   - 手順を書くのに足りない情報があれば、何が足りないかを最後にまとめる

出力は Markdown で、絵は `frames/` からの相対パスで参照してください。
