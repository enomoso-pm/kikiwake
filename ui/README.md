# Kikiwake の画面（ui/）

Kikiwake（聞き分け）の画面。React 18＋TypeScript＋Vite。
受け渡しの約束の正は `../contract/`（版10）。本物のエンジンとのつなぎ `src/api/tauri.ts` は、エンジン側（`../src-tauri/`）と組で直す。
画面の設計（UI 画面仕様書 ver1.1・動く見本）は公開していない。下の「仕様書に無くて決めたこと・仕様書と違う所」は、その仕様書と違う所の一覧。

## 状況

- 画面は**録音が主役の形**（案A。2026-09-27 に製品の画面にした）: 左に録音の一覧、右に選んだ録音（「話者」「文字起こし」のタブ）。
  前の形（上の工程バー「1 録音 2 文字起こし 3 名前付け 4 結果」・履歴の画面・完了の画面）は、アプリの中で案A を通したあとに消した（2026-09-27 決定）
- 見本データでも本物のエンジンでも通しで動く。アプリの中（Safari と同じ WebKit）では、`../scripts/e2e_mac.sh` が開発用のビルドだけに入る操作役で自動で通す（ボタンを押して読む。ui/ のファイルは使わない）
- 自動テスト（`npm test`）・型チェック・ビルドが通る
- 画面の言語は日本語と英語（2026-09-27）。文字は `src/i18n/` の辞書にあり、窓の右上で切り替えられる（下の「画面の言語」）
- 閉じたときの状態（2026-09-27。約束 版8）: 入れかけの名前と文字起こしの手直しは変わるたびに作業フォルダへ書き、開き直すと閉じたときのタブに戻る
- 新しい版の知らせ（2026-09-27。約束 版10）: 起動したときに一度だけエンジンが GitHub に尋ね、新しい版があれば新しい録音の画面に帯を出す（下の「新しい版の知らせ」）
- 言葉の決まり（2026-09-27）: 同じものを別の言葉で呼ばないよう、画面の言葉をそろえた（下の「言葉の決まり」）

## エンジンとの受け渡しの細かい所

- Tauri は `npm run build` の `dist` を使い、`tauri dev` のときは開発サーバ（1430 番）を読む
- 製品のビルド（`npm run build`）には、見本・見本データ・開発用パネルは入らない。インラインの script・eval・外部の読み込みも無い
- 全体の見た目（`styles/app.css`）は、ほかの見た目（`objects/objects.css` など）より先に読む（`main.tsx`。後に読むと、同じ強さの指定で全体の見た目が勝ち、一覧の横の右の列が下に回る）
- 呼び方の約束:
  - `applyNames` には名前の入ったラベルだけを渡す。同じ人にまとめた名前（全角・半角の違いは同じとみなす）は、一覧で上のラベルの書き方にそろえて渡す
  - `saveOutputs` の `edits`: `names` はラベルの名前と違う行だけ（確認用の行は、確定していなくても名前があれば入れる）、`confirmed` は確定した確認用の行、`texts` は直した最後の文字。何も無ければ `edits` を付けない
  - 同じ名前のファイル（`SaveResult.existing`）が返ったら確認のダイアログを出し、「上書きする」で `overwrite: true` を付けて呼び直す
  - `recordingSrc` は行の ▶ を押したときに呼ぶ。`audioSrc` はサンプルと確認用の手がかりの再生で呼ぶ
  - `onCloseRequested` が来たら（処理中だけ届く）「閉じる確認」を出し、「閉じる」で `closeApp()`。見ていない処理中の録音でも出し、文は処理中の録音の段階と順番待ちの数で決める（下の「閉じるときの確かめ」）
  - `saveDraft` は、処理が終わった録音の話者・文字起こしのタブにいる間、閉じたときの状態に関わる所が変わるたびに呼ぶ（`store/draft.ts`）。
    `unsaved` は「保存したあとで変えたか」（`store/result.ts` の `changedSinceSave`。行の手直しと、保存したあとで名前・形式・保存先を変えたこと）、`savedOnce` は保存したことがあるか（約束 版9）
  - 録音を開いたとき（`JobDone`・`HistoryOpened`）は、どちらのタブで開くときも文字起こしの中身（`getTranscript`）を読み、入れかけの名前・手直し・タブを1回の setState で戻す（`store/naming.ts` の `enterNaming`）
  - 書き終えた録音は `openHistory`、中断した録音は `startJob(path)`（続きから）。処理中なら順番待ちに入れる（エンジンは同時に1本だけ処理する）
  - ドラッグ: アプリの中では `onFileDragOver` の位置で、新しい録音の画面では枠 `[data-drop-zone]` の色、ほかの画面では窓全体の案内を出す（`store/file.ts`・`objects/store.ts`）。見本（ブラウザ）は HTML5 のドラッグ
  - 新しい版の知らせ: 起動したときに一度だけ `checkUpdate()`（設定で外していれば呼ばない）。リリースのページは `openReleasePage(version)`（URL はエンジンが作る）

## 録音が主役の画面（案A。2026-09-27 に製品の画面にした）

要望「履歴から過去の録音を出せるのに、新しいファイルを選ぶと戻れず行き来できない。OOUI の考え方で、どこからでも行き来できるように」。
3案（A 左に一覧・B 一覧がホーム・C 出口を足すだけ）から **A** を選び、見本で見比べたうえで製品の画面にした（前の形は消した）。

- **形**: 左に「＋ 新しい録音」・録音の一覧（文字起こし中 → 順番待ち → 前に文字起こしした録音）・「AI モデルと動作条件」。右の一番上の帯に録音の名前と状態の印、その下に情報・元のファイルの帯・「話者」「文字起こし」のタブと「詳細」（「…」のメニューは 2026-09-29 に外した。下の「2026-09-29 の直し」）
- **状態の印**（一覧と録音の上で同じ。2026-09-27 決定: 保存を軸にした6つ）: 順番待ち（次／2番目）・文字起こし中 42%・中断・保存前・保存済み・保存後に手直し。
  名前が付いているかは印にしない（名前を付けなくても保存できるため）。「保存後に手直し」は、保存したあとで行を直した・名前や形式や保存先を変えたとき
- **一覧の行**: 名前・日付・長さと、名前を付けた録音は「松本・田中ほか2人」（発言の多い順に2人と残りの人数。約束 版9 の `namedSpeakers`。2026-09-27 決定）、付けていなければ「話者 4・名前なし」。元のファイルに問題があれば一言（見つかりません／変わっています）。開いている録音は画面の今の値で出す
- **並び**: 前に並べた順を保ち、新しい録音だけ上に足す（エンジンは最後に使った順で返すので、そのまま並べると手直しするたびに行が動く）。元のファイルを結び直して録音の ID が変わっても、場所は変えない
- **処理は同時に1本**: 処理中に足した録音は**順番待ち**（画面だけが持つ。アプリを閉じると破棄する＝閉じるときの確かめに書く）。前のものが終わると、一覧を読み直す前に次を始める（読み直している間に閉じると、エンジンが処理中でないので確かめずに閉じ、順番待ちが消えるため。そのあいだ終わった録音の行は仮の行で出す）
- **処理中にほかの録音を開ける**: 処理中の録音は `objects/store.ts` が知らせを受けて持ち続ける。見ていない録音が終わったら知らせ（トースト）と一覧の「●」（開くと消える。アプリを閉じても覚える: `localStorage` の `kikiwake.fresh`）
- **閉じるときの確かめ**（2026-09-27 決定: 何が残り、何を破棄するかを正確に。「破棄します」）: 処理中の録音の段階で3通り（声の聞き分けの前／声を文字にしている間／まとめている間。`lib/close.ts`）と、順番待ちがあれば「順番待ちの n 件は破棄します。まだはじめていないので、元のファイルも文字起こしも失いません。」
- **完了の画面はなくした**: 保存したかは状態の印に出る。別の録音は「＋ 新しい録音」、終わるのは ⌘Q
- **はじめの準備**: AI モデルがそろうまで（「はじめる」を押すまで）は、一覧・上の帯・タブを出さず、準備の画面だけを出す。そろったあとは一覧の下の「AI モデルと動作条件」で見返す（題「AI モデルと動作条件」・「次へ」なし・足りないモデルがあるときだけダウンロード・「もう一度確かめる」・新しい版の確認の設定）
- **下の帯は保存だけ**: 「話者」「文字起こし」のどちらのタブでも、下は保存の帯（2026-09-29 から「保存…」のボタンだけ。形式と保存先は押して開く窓で選ぶ。下の「2026-09-29 の直し（2回目）」）。「話者」のタブから保存すると、入れた名前を確定してから保存する。名前を付けなければ「話者A」などのまま保存する
- **「詳細」はどちらのタブでも**: 話者のタブで開くと、入れた名前を確定してから開く（発言時間は名前でまとめて数えるため）
- **切り替えても高さが変わらない**: タブと操作の段の高さを決めておく。名前を変えずにタブを切り替えても「保存済み」の印は変えない（2026-09-27 に直した）
- **ファイルを落とす**: どの画面でも（準備の画面を除く）、窓に落としたファイルを新しい録音として受ける。ドラッグ中は窓全体に「ここに落とすと、新しい録音として追加します」（新しい録音の画面はドロップ枠の色）
- **窓の幅**: 1100px 以上は一覧を横に置き（しまえる）、それより狭いと左上のボタンで重ねて出す。最小の窓（900×560）でも中身に 320px を残し、帯が並んだら右側全体をスクロールする
- **元のファイル**（約束 版9 の `sourceState`）: 「見つかりません」（場所にファイルが無い。書き起こし・名前・手直しは残り、行の再生だけできない。外付けのドライブにあれば、つないでから開き直す。「ファイルを選び直す」）と
  「変わっています」（場所にあるが大きさか更新日時が違う。長さが同じなら「このファイルで結び直す」、切った・つないだなら「新しい録音として文字起こしする」）を分ける。
  変わったファイルを新しく選ぶと「この場所の録音は、前に文字起こししています」（約束 版9 の `FileInfo.previousChanged`）。保存したファイルを移した・消したときは一覧の行の「…」の「Finder で表示」で気づき、その録音を開いて帯で「もう一度保存すると作り直せる」と出す
